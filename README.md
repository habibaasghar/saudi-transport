# Ride Saudi

Static home page for ridesaudi.com, backed by Supabase.

- `index.html` – home page
- `config.js` – Supabase URL + anon key
- `supabase.sql` – creates the `waitlist` table (run in Supabase SQL Editor)

Deploy: import this GitHub repo in Vercel (no build settings needed), then add `ridesaudi.com` under Project → Settings → Domains.
