## How to request indexing

1. Search Console → URL inspection (top bar). Paste the URL.
2. If it says "URL is not on Google", click **Request indexing** and wait for the confirmation.
3. If it says "Quota exceeded", stop and continue the next day.

To track the queries, go to Performance → Search results → + Add filter → Query → "Queries containing". Use a short stem such as `سطحة`, `لوبد`, `satha` or `lowbed`. First impressions usually appear 1–3 weeks after indexing.
