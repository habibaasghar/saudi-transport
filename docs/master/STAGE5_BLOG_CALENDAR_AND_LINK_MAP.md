# Stage 5: Blog Content Calendar and Internal-Link Map (2026-11-18)

## 1. The rule used to decide every topic

A guide is built only if:
- it answers an **informational** question (how, which, compared with what);
- no commercial page already answers that question; and
- it can be written from checked facts.

If a commercial page already targets the topic, that page is improved instead. This avoids two URLs from one site competing for the same search, which the brief forbids.

The site has 4 guides today:
- cross-border checklist;
- car vs flight vs rental;
- choosing vehicle size;
- airport pickup tips.

**Rules for writing each guide:**
- Every fact needs a source: train timetables and fares from SAR or Haramain official pages, airport facts from the airport's site, and road distances and times from the routing engine plus Google Maps, with the check date.
- If a fact can't be verified, it is left out.
- Arabic is written natively, not translated, and uses the terms from `docs/phase1/ARABIC_KEYWORD_RESEARCH.csv`.
- Fare comparisons follow the brief: never claim a private car is always faster or cheaper.

## 4. Internal-link map

### 4.1 Rules (now in the template, so they hold for every future page)

| From | To | How |
|---|---|---|
| Route page | Reverse route, origin and destination airports, related services | `related` list (hand-picked per page) |
| City hub | **Every route starting or ending in that city** | **New, automatic:** a "Private routes to and from this city" block built from the registry. Routes already in `related` are skipped, and Buraidah is matched to the "buraydah" route slug. |
| Any service, route or city page that a guide cites | **That guide** | **New, automatic:** a "Planning guides" block, built from each guide's `links` list |
| Guide | Commercial pages first, then routes and cities | Guide `links` list (validated at build) |
| Header menus | Hubs and the 14 priority routes | `src/lib/nav.ts` |

Anchor text is always the target page's own short name (`nav`). There are no keyword-stuffed exact-match anchors.
